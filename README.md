# 小丑牌 JOKER

一款受 Balatro 启发的轻量网页卡牌游戏。拿到 8 张手牌以后，从中选出 1 到 5 张组成牌型，在有限的出手机会里凑够分数，再去商店挑选能改变倍率的 Joker。完整牌局分为两幕，共有 6 个逐步加压的盲注。

## 一局怎样进行

开局会从一副完整的 52 张扑克牌里抽出 8 张。点击手牌即可选中，再决定出牌或弃牌。每次最多出 5 张，界面会提前显示牌型和预计得分。

每关有 4 次出手机会和 3 次弃牌机会。得分按照牌型基础筹码、牌面点数与倍率计算，出牌后可以看到每张牌逐一加入筹码，最后显示完整算式。达到目标分数以后进入商店，用金币购买 Joker，再继续挑战下一档盲注。

| 关卡 | 目标分数 |
| --- | --- |
| 🔵 小盲注 | 300 |
| 🟡 中盲注 | 500 |
| 🔴 大盲注 | 800 |
| 🟣 暮色盲注 | 1200 |
| 🌙 幻影盲注 | 2000 |
| 👑 终局盲注 | 3200 |

前三关组成第一幕，用来熟悉牌型并买到最初几张 Joker。第二幕的目标从 1200 分一路升到 3200 分，玩家需要围绕已经拿到的效果调整选牌。通过全部 6 关就算完成一局。手数用完仍未达到目标，游戏结束，可以立即再来一局。

## 牌型与 Joker

游戏支持同花顺、四条、葫芦、同花、顺子、三条、两对、对子和高牌，共 9 种牌型。A 同时支持高顺与 A、2、3、4、5 的低顺。

商店会随机给出 3 张 Joker。当前共有 12 种，最多持有 5 张，效果会按摆放顺序依次结算。没有适合当前打法的商品时，可以花 2 金币重新进货。是否把金币留给下一家商店，也会影响后半局能否凑出完整组合。

| Joker | 效果 |
| --- | --- |
| 🃏 小丑 | 每手增加 4 倍率 |
| 📖 学者 | 打出的每张 A 增加 4 倍率 |
| 🌓 半张小丑 | 出牌不超过 3 张时增加 8 倍率 |
| ✌️ 偶数史蒂文 | 每张偶数牌增加 2 倍率 |
| 🎲 奇数托德 | 每张奇数牌增加 2 倍率，A 也算奇数 |
| 🙂 笑脸 | 每张 J、Q、K 增加 3 倍率 |
| ❤️ 红心收藏家 | 手牌含红心时倍率乘 4 |
| ♣ 梅花爱好者 | 手牌含梅花时倍率乘 4 |
| 👑 皇家头牌 | 手牌含 J、Q、K 时倍率乘 10 |
| ⚙️ 对子引擎 | 对子或更高同点牌型增加 40 筹码 |
| 🚩 同花旗手 | 同花或同花顺增加 60 筹码 |
| 🔥 同花顺大师 | 打出同花顺时增加 50 倍率 |

## 我觉得好玩的地方

选牌以后，筹码和倍率并不会一下跳到结果。牌会飞到计分区，点数逐张加入，Joker 再按顺序触发，最后才出现整手牌的算式。这个过程让玩家看得懂分数从哪里来，也能很快意识到下一轮该围绕哪张 Joker 组织手牌。

不想慢慢比较时，可以按下“AI 出牌”。它会检查 8 张手牌中由 1 到 5 张牌组成的全部 218 种组合，选择当前得分最高的一手。商店里也会给出购买建议。它很适合第一次接触这类玩法的玩家，也可以拿来观察当前 Joker 组合偏爱什么牌。

扩充后的牌池可以形成几条清楚的路线。少出牌可以配合半张小丑，偶数与奇数 Joker 会改变玩家保留牌的标准，人头牌可以同时触发笑脸与皇家头牌。对子引擎负责补筹码，同花旗手则给同花路线一个稳定的中期选择。到了第二幕，只追求当前最高牌型未必够用，持续触发手里的 Joker 往往能拿到更高分数。

音乐会跟随牌局、商店、胜利和失败切换。设置面板可以分别调整背景音乐与音效音量，还能切换动画速度和计分公式显示。

## 本地运行

项目需要 [Bun](https://bun.sh)。

```bash
git clone https://github.com/ebon-gryphon/joker.git
cd joker
bun install
bun run dev
```

浏览器打开 [http://localhost:5173](http://localhost:5173) 即可进入开发版本。

生产构建与本地预览可以使用下面两条命令。

```bash
bun run build
bun run preview
```

构建产物会生成在 `dist/`。

## 技术实现

| 部分 | 使用的技术 |
| --- | --- |
| 界面框架 | Vue 3 Composition API |
| 构建工具 | Vite 5 |
| 动画 | GSAP 3 |
| 音频 | Web Audio API 与 HTML Audio |
| 状态保存 | localStorage 保存音量、静音与动画设置 |
| 在线发布 | GitHub Pages 与 GitHub Actions |

当前版本为 `v0.2.0`。规则测试使用 Node.js 内置测试运行器，覆盖两幕关卡、Joker 唯一性和新增计分效果。

推送到 `main` 分支后，GitHub Actions 会构建项目并自动更新[在线试玩页面](https://ebon-gryphon.github.io/joker/)。
