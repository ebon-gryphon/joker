# 冒险模式独立 Demo · 路线实验 V2

不导入或修改经典模式代码，不接入主菜单。无需安装依赖。

在此目录运行 `python3 -m http.server 4178 --bind 127.0.0.1`，打开 http://127.0.0.1:4178 。

- 12 层约束生成地图：每种子固定，支持重开比较路线或随机换图。
- 首战教学，中途宝箱合流与重新分叉，两个可绕行的精英层，Boss 前固定整备。
- 点击节点先看风险、收益和后续可达机会，再进入绿色节点。
- 普通 / 精英 / Boss 的未达标中间手承受 2 / 3 / 4 生命压力（首战 0）；最后一手按缺口扣血，不重复叠加压力。提前达标、弃牌均无本手压力。
- 三种预告 Boss；精英奖励自选；未知房间可能揭晓三类事件、战斗或商店。
- 生命、金币、永久筹码、小丑牌与补给跨节点保留。页面刷新重置至默认种子；不保存进度。

规则测试：项目根目录运行 `node --test demo/adventure/engine.test.js`。包含 200 张种子地图的全路径约束检查。

设计拆解为 `route-design.html`（单文件，离线可读），页面顶部也有入口。公开资料只作为设计启发；我们的生成器和概率不是原作算法。计分仍为简化独立版本，数值未完成平衡。
