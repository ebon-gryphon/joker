# 小丑牌玩法拆解与牌库扩充

## 从原作到本作

[Balatro 官方 FAQ](https://www.playbalatro.com/faq) 描述的循环是打出扑克组合、达到盲注分数、进入商店构筑下一轮；小丑牌既能改变计分，也能改变牌的作用或提供经济收益。原作还有 Boss 限制、塔罗牌改牌等系统。本次聚焦现有项目的 Joker 库，保留六关、52 张牌、五个 Joker 槽和每店三个商品的结构。

以下设计判断来自本项目代码。扩充前有 12 张 Joker，多数效果只增加倍率，缺少持久成长与经济路线。红心、梅花仅需一张即可 ×4，皇家头牌仅需一张人头牌即可 ×10，使低门槛乘倍率压过普通牌。卡槽只进不出，且虽然按顺序结算，玩家不能主动调整顺序，难以在后期换路线。

本作是短局改编，以下卡名与数值包含自行设计和调优，并不声称完整复刻原作。原作的更细计分牌规则、重触发、改牌和复制效果本次未引入；本作仍将所有打出的牌计入基础筹码。

## 设计落地

| 构筑决策 | 本次实现 | 取舍 |
| --- | --- | --- |
| 补筹码还是补倍率 | 蓝色小丑、方片矿工、顺子铁轨；开心小丑、杂技小丑、同花剧团 | 筹码与倍率相乘，缺哪项补哪项 |
| 围绕哪些牌选牌 | 四花色路线、人头牌、偶数、奇数、斐波那契、4/10 | 限定匹配牌，不能每手无条件爆发 |
| 现在得分还是投资后期 | 长跑选手、方块小丑、绿色小丑 | 要持续打出指定组合或少弃牌才能成长 |
| 花钱买牌还是留钱 | 黄金小丑、回收员、金牛 | 经济牌占用宝贵卡槽，金牛封顶 +60 筹码 |
| 保留还是用尽资源 | 节制旗帜、孤注一掷、压轴演员 | 剩余弃牌和手数会影响最优出牌 |
| 怎样安排结算顺序 | 左右调序、同时展示加筹码及倍率的动画 | +倍率后 ×倍率通常更有利 |
| 是否换掉早期牌 | 商店出售返还半价，允许腾槽 | 已售商品本次货架不可重复买入；刷新后可再次抽到 |

32 张牌包含 20 张普通、11 张稀有、1 张传说。完整效果以游戏图鉴及 README 的清单为准。商店继续先抽稀有度、再抽该类别内的牌，扩池不会改变各关原有稀有度权重。

## 修改原有卡牌

- 红心收藏家、梅花爱好者改为打出至少三张对应花色才 ×2，价格仍为 $5。
- 皇家头牌改为打出至少三张 J/Q/K 才 ×2，价格由 $5 调整为 $6。
- 同花顺大师保留同花顺 +50 倍率，并增加普通顺子、同花 +10 倍率，让罕见卡牌在未凑出同花顺时也有用途。
- 其余原有牌保持数值，描述明确检查打出的牌。

## 结算与状态

`jokerCatalog.js` 集中管理牌面说明和效果。`calcScore` 是纯计算，会返回逐张结算轨迹；界面预览、AI 选牌及正式出牌复用它，动画直接播放返回的轨迹，不再重复推演成长后的状态。

成长牌在出牌提交时仅累积一次，在本手计分中提前计算这次增长；弃牌只改变绿色小丑成长与回收员金币。成长在过关后保留，重开清零。商店购买复制定义，避免把成长状态写回全局牌库。过关时显示基础收入与黄金小丑奖励，最终过关同样结算奖励。

AI 出牌仍然只优化当前一手分数，不规划未来经济和成长收益。商店建议仍是稀有度与价格的简单启发，不等同于对整套构筑的评估。牌槽满时隐藏购买建议。

## 验证与限制

规则测试覆盖新增 20 张卡的计分、条件不满足、乘法顺序、成长只提交一次、跨关保留、重开清零、经济奖励、重复购买、出售和调序，以及预览/AI/实际得分一致。原有关卡与商店稀有度分布测试继续保留。

数值以六关短局的首轮设计为准，未做大规模胜率或所有组合的平衡模拟。后续调优应观察过关率、各牌购买率和路线使用率，而不是继续提高单张卡的倍率。
